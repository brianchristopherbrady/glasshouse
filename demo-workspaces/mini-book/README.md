# mini-book (demo)

No code, no package manager -- just a manuscript with an explicit
`flowbook.members.json` declaring a Part -> Chapter hierarchy, to give
Flowbook's Workspace Map a real `source: "config"` graph.

Chapter 4 is the in-universe counterpart to the widget status lifecycle
(active -> archived) implemented in the sibling `mini-monorepo`/`mini-app`
demo repos -- see `demo-workspaces/README.md`.
